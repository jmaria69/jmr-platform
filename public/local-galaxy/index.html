Arquitectura

Tres componentes. Un sistema.

Cada pieza tiene una función específica. Juntas forman una infraestructura de agentes autónomos que opera sin salir del perímetro.

🪐
Obsidian
// Núcleo de memoria
Base de conocimiento privada sobre archivos Markdown. Segunda memoria permanente accesible tanto por humanos como por agentes IA. Sincronización mediante repositorio Git local — sin nube, sin exposición.
🦅
Hermes
// Agente operativo
Agente autónomo local que lee, indexa, procesa y escribe de forma autónoma dentro de la bóveda de conocimiento. Conectado vía variables de entorno al sistema local o VPS. Opera 24/7 sin intervención humana.
⛵
Odysseus
// Orquestador RAG
Motor de búsqueda semántica sobre la base de conocimiento privada. Enruta el contexto exacto a Hermes para ejecuciones autónomas de fondo. Retrieval-Augmented Generation sin depender de ninguna API externa.
Flujo de datos

Cómo funciona

El dato entra, se indexa localmente, y el agente actúa. Todo dentro del perímetro.

input() Consulta / Tarea
→
odysseus.rag() Búsqueda semántica local
→
hermes.think() LLM on-premise
→
obsidian.write() Acción + Memoria
